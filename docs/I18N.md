# Doppel translation guide

English in [en.ts](../src/lib/i18n/en.ts) defines the schema. Phase A ships English copy and localized what-if examples. Phase B replaces each of [de.ts](../src/lib/i18n/de.ts), [fr.ts](../src/lib/i18n/fr.ts) and [tr.ts](../src/lib/i18n/tr.ts) with a complete object literal using `satisfies Messages`. Keep the same keys and placeholders, including number format suffixes. Add new keys to English and each locale in the same change.

## Using messages

- Components call `useI18n()` and use `t("section.key", params)` for a string, `tm(text)` for a descriptor or plain data, and `rich(key, params)` when a placeholder needs a React element.
- Libraries return `msg("section.key", { amount })`. Keep numbers raw and pass nested descriptors for built-in labels. User-entered text, extracted document text and names remain plain data. Use `translate("en", key, params)` or `translateText("en", text)` for English data sent in a model prompt.
- `{name}` inserts a value. `{amount:chf}`, `{amount:chfShort}`, `{p:pct}`, `{p:pct1}`, `{count:int}` and the other [supported formats](../src/lib/i18n/index.ts) render raw numbers. Fractions are used for percentages, so `0.4` becomes `40%`, `40 %` or `%40`. CHF always uses Swiss grouping, as in `CHF 1’234`. Use `fmt` for individual numbers and month names.
- Keep `label_one` and `label_other` plural forms and call `t("section.label", { count })` without a suffix. Selection follows `Intl.PluralRules`, with `_other` for categories without a dedicated form. Check zero, one and several for token counts, receipts, subscriptions, waiting years, pension bridge years and measured calls.
- Server output and the first render use English. The provider reads the saved choice or browser languages after mount. Render values that depend on the browser clock, such as timeline months and simulation wall times, after `mounted`.

## What-if examples

The six `cmd.examples` strings in each dictionary appear as command chips. The check runs every chip through its own locale's parser and through `localParseCommand`. Preserve the example's intent, date, amount and duration when changing its wording, and update the corresponding parser in [src/lib/twin/intents](../src/lib/twin/intents) when needed. Each `IntentParser` receives the original text, current date and planned home, and returns unvalidated ops. `localParseCommand(text, events, now, locale)` validates those ops and tries the active locale before the others. House-delay examples need a planned home, which the check takes from Meriç's account (`PROFILE_WITH_HOME`).

## Glossary and short labels

| Language | Terms and translation notes |
| --- | --- |
| German (Switzerland) | Use Swiss Standard German with `ss` everywhere. Use AHV, BVG / Pensionskasse, Säule 3a, Tragbarkeit, Hypothek, Eigenmittel, Lohnabrechnung and Nettolohn. In the mortgage card, keep bank-calculated costs and actual closing costs distinct. Check the lengths of risk controls, the Plan A chip and short scan labels. |
| French (Switzerland) | Use AVS, LPP / caisse de pension, 3e pilier (pilier 3a), capacité financière (taux d’effort), hypothèque, fonds propres and fiche de salaire. Use the narrow no-break space before percent signs in fixed copy. For “Home” versus “Listing”, distinguish the purchase event from the property advert. Check compact switches and the plural forms for 0 and 1. |
| Turkish | Use concise, natural Turkish and retain Swiss institution names with a short gloss on first use, for example “AHV (devlet emekliliği)”, “3a (bireysel emeklilik)” and “Tragbarkeit (banka ödeme gücü testi)”. Write percentages with the sign first. After a number, Turkish nouns usually stay singular. Test the room and date phrasing, the risk buttons and the what-if suffixes. |

“Cash crunch” means that liquid assets run out. “Real you” includes modeled spending and selling habits, and “Disciplined you” removes those habits. “Naive baseline” is the GPT-4o comparison method. “Pension bridge” is the gap funded from savings before AHV/AVS starts. Keep Doppel, CHF, model names, tier designations and route identifiers unchanged. Keep short labels legible at 320 px.

Run `npm run i18n:check` or `npx tsx scripts/i18n-check.ts` before handing off a dictionary. In Phase A use `npm run i18n:check -- --allow-untranslated` to count English fallback values as warnings. Structural, placeholder, spelling and parser errors still fail the check.
